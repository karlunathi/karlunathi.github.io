# Karl Unathi — Portfolio

Static site hosted on GitHub Pages at https://karlunathi.github.io

## Before you push: fill in these items

1. `js/main.js` — set `CONFIG.email` (and `CONFIG.formspreeId` if you use Formspree).
2. `assets/profile.png` — your photo (4:5 portrait). Until it exists, a "KU" badge is shown.
3. `assets/Karl-Unathi-CV.pdf` — your CV, for the Download CV button.
4. `index.html` — search for `TODO` and confirm the LinkedIn URL, add the company name,
   dates and measurable results to the Experience cards, and tune the skills list.

## Deploy

Copy everything in this folder to the root of the `karlunathi.github.io` repo, then:

    git add .
    git commit -m "Update portfolio"
    git push

GitHub Pages republishes automatically within a minute or two.
The repo must be public and named exactly `karlunathi.github.io`.

## Optional: custom domain

Not required. If you buy one later, add a `CNAME` file containing only the domain,
point the DNS records to GitHub Pages, and enable Enforce HTTPS under Settings → Pages.
